Configuration

How many consecutive missed reports before a node counts as offline. Three is the default — one miss is ordinary on 2.4 GHz, so the minimum is two.

Note: WiFi nodes are configured via their own captive portal, and registered on this collector via platform_config.json sensor entries of type "remote".
