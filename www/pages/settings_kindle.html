Settings / E-ink dashboard
Open the page

/kindle is drawn on the collector and served to the reader as finished HTML — there is no script on it and nothing to configure from the reader itself, which is why these live here. A change takes effect on the panel's next repaint.

Typeface

Which faces a reader can actually reach depends on its firmware. Every choice falls back to a generic family, so a face the device does not carry renders in the browser's default rather than in nothing.

Written straight into the page's stylesheet, so it is filtered down to letters, digits, spaces, commas, quotes and hyphens. End it with a generic family.

Clock

Drawn only by the dated clock style.

No style shows seconds. The panel repaints on a timer measured in minutes, so a seconds field would be wrong the moment it was drawn.

Weight

Which figures are set bold. Nothing is, by default: the page's sizes already carry the hierarchy, and weight on top of them is for a shelf far enough away that size alone stops being enough. These apply by size, to every reading of that size — to set one particular reading bold, use its own B switch under Readings on the dashboard below.

What is drawn

All on by default. Turning things off is for the reader who wants the page to be two numbers and nothing else — every block removed gives its height back to the ones above it.

Weather forecast

The forecast provider, coordinates, and outlook mode (hourly / daily) are configured under Settings → Modules. The outlook setting controls whether the three columns on the e-ink page show the next hours (+3 h, +6 h, +9 h) or the next days.

Units

The three-hour change follows the same unit.

Whole degrees set the big numerals wider apart.

Refresh cadence

How often the reader reloads the page. Every reload repaints the whole panel, which flashes and costs battery. 'Follow data' predicts when the next reading is due and reloads right after. 'Clock sync' aligns the reload to the minute boundary so the displayed time changes when the minute does.

Sensor mapping

The sensor IDs (from the Sensors page) that populate the outdoor and indoor sections of the dashboard. Leave blank to use the firmware defaults.

FBInk settings

Screen resolution for the FBInk Kindle script. Affects graph dimensions and icon sizes served by /kindle/data.

Readings on the dashboard

Each row below is one reading on the e-ink page, drawn in this order. A reading whose sensor is not reporting is skipped and the row closes up behind it — so a BMP280 outside simply has no humidity line, rather than a permanent dash.

Size decides both the type size and how much of the width it takes: a hero fills the row on its own, then large is a half, medium a third and small a quarter. They pack left to right and wrap.
