Sensor CSV logging

Wide-CSV stores sensor readings as one row per aggregation window with one column per active sensor metric. The header is rebuilt dynamically when sensors are added or removed; the per-day file rotates automatically on schema change. Independent of the flow-meter event log on the Data Log page.

Master switch. When off, sensor readings are still streamed to the live UI but never written to flash/SD.
